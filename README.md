# User Management System (PHP)

Esercizio del corso Formarete 2020-21, *Linguaggio di programmazione PHP*: gestione utenti con PHP e MySQL.

Contenuto:

- `src/entity/User.php`: la classe `User`;
- `src/model/UserModel.php`: accesso al database con PDO;
- `src/validator/`: validazione e sanificazione dei campi del form (`UserValidation`, `ValidationResult`);
- `src/test/`: script di prova per la creazione degli utenti e per la validazione;
- `__database/`: query SQL per creare e svuotare la tabella;
- `__docs/uml/`: diagramma del flusso "nuovo utente";
- `TODO.md`: i passi del flusso di inserimento.

Repository derivato da [corsidrive/user-management-system](https://github.com/corsidrive/user-management-system). La versione completa è in [usm_versione_finale](https://github.com/Matteo-Caridi/usm_versione_finale).
